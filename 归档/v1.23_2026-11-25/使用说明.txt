送货单  使用说明   版本 v1.22（2026-11-25）
==========================================================

一、这是什么
  按「开异模板」的送货单格式录入、打印送货单的小工具。
  已适配：Epson LQ-300K+ / LQ-630KII 针式打印机 + 214.7×139.8mm 三联纸（打印机表单里显示为
  21.47×13.98，默认版式）。这一版就是按你机器上那张纸的实际尺寸排的，纸宽不再是 241。
  也保留了 A4 版式，可用激光/喷墨打印机打印或存 PDF。

二、文件说明（都在本文件夹里）
  送货单.html   主程序（双击也能直接用浏览器打开）
  启动送货单.bat      推荐用它启动：会以独立窗口打开，像一个小软件
  start.ps1           bat 调用的启动脚本（不要改名）
  样张\三联纸_模板同款.pdf       单页样张，和原模板同一份数据，最适合拿来对位置
  样张\三联纸_214.7x139.8_样张.pdf  6 行满页样张（按新纸尺寸排的，看分页/小计/合计）
  样张\三联纸_铺满纸底_样张.pdf     1 行 + 表格铺到纸底的样张（对比用）
  样张\三联纸241x140_样张.pdf      旧 241×140 版式留档（新版不用它）
  样张\A4_样张.pdf               A4 版式样张
  样张\三联纸_样品单示例.pdf      样品单抬头样张（2 行、合计、送货人）
  样张\三联纸_字号放大示例.pdf     字号放大样张（标头 130% / 单据信息 120% / 货物明细 115%）
  样张\三联纸_加粗示例.pdf         加粗样张（标头与表头粗体）
  使用说明.txt        本文

  注意：单据记录保存在本机浏览器里，不要把 html 文件单独拷走就算搬家，
       换电脑时请用软件里的「导出备份 / 导入备份」迁移。

三、第一次使用：给打印机建 214.7×139.8mm 纸张（21.47×13.98cm）
  1. 控制面板 → 设备和打印机 → 右键 Epson LQ-630KII → 打印服务器属性。
  2. 勾选「创建新表单」：
       表单名称：三联纸21.47x13.98（名字随便起，关键是下面两个数字）
       纸张宽度：24.1 cm
       纸张高度：14.0 cm
     点「保存表单」。
  3. 打印机属性 → 首选项 → 纸张大小选「21.47×13.98」（就是你截图里那张表单）；
     纸张来源选「连续纸 / 拖纸器（Tractor）」。
  4. 装上三联纸，压好拖纸器两侧的定位孔，纸张松紧调平。

四、日常使用
  0. 先认界面：窗口最左边是一条竖着的导航栏，四个图标切换四块内容，右边「打印预览」始终不动：
       录单     —— 填单据信息 + 录货物明细（平时就在这块）
       版式字号 —— 打印版式（三联纸 / A4）、上下微调、三块字号、打印设置说明
       选项列宽 —— 下拉候选的「选项管理」、明细的「列设置」
       记录备份 —— 打开记录库、导出备份/导入备份、导出货物明细/导入货物明细
     顶栏只剩 新建 / 保存 / 复制本单 / 打印，右边那个小标签显示当前版式（三联纸 214.7×139.8 或 A4 纸）。
  1. 双击「启动送货单.bat」。点「新建」就是一张干净单：制单人 / 经办人 / 送货人 / 部门 /
     发货仓库 / 客户 / 摘要 全部清空，单据编号也清空，日期换成今天；公司抬头和单据类型保留。
  2. 左侧填写单据信息；单据编号可以不填 —— 点「保存」或「打印」的那一刻才自动补上
     「前缀-日期-流水号」（按当天已存单据往后排），也可以自己先填好。
       · 前缀跟着单据类型走：送货单 XS、样品单 DB、提前送货单 TQ
         例：送货单 XS-2026-11-25-00003、样品单 DB-2026-11-25-00008
       · 流水按各自前缀单独算，送货单和样品单不会互相占号
       · 自己填的编号不会被改日期、换版式动到；只有 XS / DB / TQ 开头的自动号才会跟着重排
       · 手动填了一个比自动号大的（如 DB-…-00099），下一张自动号会接着 00100 排，不会撞号
       · 切换单据类型时，自动号只换前缀、保留原流水（XS-…-00005 → DB-…-00005）；
         这个号在新前缀下已被占用，才自动往后顺延
     「送货人」填上名字就打印在单据底部「送货人：某某」的位置（代替手写）；
     留空则只印“送货人”三个字，由人签字。填过的名字会存成候选（点框右边 ▾ 能选回来），
     但点「新建」时单据信息一律清空，不会把上一张的人带过来。
     单据最底下一行的签字栏顺序是：财务（左）— 送货人（中）— 购货单位签字（右）。
     单据信息标题行右边有三个类型按钮：送货单（默认）/ 样品单 / 提前送货单。
       点一下就切换，打印抬头跟着变成「公司名 送货单」「公司名 样品单」「公司名 提前送货单」；
       编号留空就等保存时自动生成（送货单 XS、样品单 DB、提前送货单 TQ 开头），想用客户的号从这里直接填；
       保存后记录库里会标出这张单的类型，新建单据沿用上次用的类型。
     制单人 / 经办人 / 送货人 / 部门 / 发货仓库 / 客户 这六个框，都是「可以自己加选项的下拉框」：
       · 点一下框里、或点框右边的 ▾，会弹出「全部候选」列表，点一下就用它；
         列表不会因为这一格已经填了谁就只剩那一个人 —— 选了「朱」以后照样能看到「齐」，
         想换人直接换（这是浏览器原生下拉做不到的，所以改成了自绘面板）；
         当前在用的候选前面打勾；面板底部还有「＋ 把当前内容存成候选」和「清空这一格」。
       · 再点一次 ▾、点面板外面、或按 Esc，面板都会收起（以前点第二下不消失，一直挂在那儿挡操作）。
       · 想加新选项：把内容填进去，点框右边的蓝色 ＋，这个值就存在本机，
         以后每次点这个框都能选到；保存过的单据里的人和单位，也会自动变成候选；
       · 加错了？点左边「选项列宽」→「选项管理」，在弹窗里点选项后面的 × 删掉
         （只删候选，已保存的单据内容不受影响）。
  3. 明细可以一行行录，也可以从 Excel 直接粘贴：
       在 Excel 里选中含「存货编号、名称、规格…」的区域 → Ctrl+C
       点明细表任意单元格 → Ctrl+V，整块导入（带表头也行，会自动跳过）。
  4. 存货编号录完（离开单元格）会自动从商品库带出名称、规格、单位、品号；
     商品库在每次「保存」时自动积累。

  4.1 货物明细记忆库（按「规格型号」自动带出名称、单位，v1.23 新增）：
      · 明细里填过的「规格型号 + 存货名称 + 单位」会自动记在本机浏览器里，录完离开格子就记，不用点保存；
      · 新单里在「规格型号」填一个以前用过的规格、离开格子时，名称和单位会自动补上；
        已经填了内容的不会被覆盖（想换就手动改）；
      · 只记「规格非空」的行，空规格、只有名称没规格的不占空间；
      · 货物明细工具栏最右边显示「已存商品 N 条」；最多 1000 条，超过后最早的自动淘汰；
      · 同一个规格只留一条，后录的覆盖先录的（同一规格不同品牌时，以最近一次为准）；
      · 左侧「记录备份」里有「导出货物明细 / 导入货物明细」，可以单独备份、换电脑迁移；
      · 「导出备份」的整份备份里也包含这部分数据，导入备份时一起恢复；
      · 存储做了压缩：只存规格/名称/单位 3 个字段、用数组不写键名，1000 条约 50~150KB。
  5. 右侧是实时打印预览，所见即所打。预览区右上角 － / ＋ 调显示比例（25%~160%，一次 10%），
     点中间的百分比数字可一键回到「适应宽度」；这里只是屏幕上看得清不清，不影响打印尺寸。
     觉得印出来字太小/太大？用左边「版式字号」里的「字号」分开调 标头 / 单据信息 / 货物明细（见第八节）。
  6. 点「打印 / 导出PDF」：
       打印机 = Epson LQ-630KII
       纸张   = 三联纸241x140
       缩放   = 默认 / 100%（不要选“适合纸张”）
       边距   = 无，取消勾选「页眉和页脚」
     想留电子档时，打印机改选「Microsoft Print to PDF」即可存成 PDF；
     另存 PDF / 用虚拟打印机时，默认文件名自动是「客户名称 + 单据编号」
     （编号框空着也没关系，打印前会自动补号再取名字），
     例如 苏州工业园区某某电子有限公司 XS-2026-11-24-00001.pdf，不用每次手动改；
     文件名里不允许的符号（\ / : * ? " < > |）会自动去掉。
     如果 PDF 打印机不支持自定义纸张、存出来被缩放，把版式切到「A4」再存。

  补：要给财务发 Excel，点顶栏「导出 Excel」（不用装任何插件，生成的是真正的 .xlsx）：
        · 列名 / 列序 / 隐藏列 / 列宽都按当前「列设置」走，跟纸面完全一致；
        · 版式照纸面来：标题、三行单据信息、表头（加粗 + 淡蓝底）、明细、合计、签字栏；
        · 表头行已冻结，数量是真数字、合计是真公式（=SUM(G8:G9)），导出后能直接筛选、加单价算金额；
        · 存货名称、规格再长也自动换行，行高跟着内容变高，不会像以前那样只露半截；
        · 全表细边框，直接打印或转 PDF 都整齐；
        · 文件名自动是「客户 + 单据编号.xlsx」，规则和另存 PDF 一样（编号空着会自动补号）。
  7. 删错了不用重新录：勾选行首方框 → 点「删除选中行」后，屏幕底部会冒出一条
     「已删除 N 行」的提示，6 秒内点它右边的「撤销」就能把刚才删的行原样恢复
     （内容、列宽都不变）；记录库里删单也一样，删完底部同样提示、同样能撤销。
     提示条 6 秒后自动消失，过期就不能撤了；连续删两次只记得最近那一次。

五、改明细行、改表头（增删列 / 拖动排序 / 改名 / 调宽）
  1. 行的编辑：任意一行、任意一个格子，单击就能直接修改，改完立即进右侧预览；
     回车跳到同一行的下一格，最后一格回车自动开新行。
     行首有勾选框，配合「添加行 / 插入行 / 删除选中行 / 上移 / 下移」整理顺序：
       · 添加行：在末尾追加一行
       · 插入行：在你勾选的那一行下面插一行（不勾选就插在末尾）
       · 删除选中行：删掉勾选的行（可多选）
  2. 列的编辑：点左边「选项列宽」→「列设置」（或者直接双击表格的任意表头文字）打开设置窗，每一列都能：
       拖动排序   —— 按住左列的「⠿ 拖」按钮上下拖，经过某一行会出现一条蓝色横线，
                     在行的上半段松手＝插到这行前面，在下半段松手＝插到这行后面；
                     也可以完全不用鼠标，用 ↑ ↓ 一格一格挪。
       列名       —— 表头文字，改完全面生效：软件表格 + 打印出来的送货单
       显示       —— 取消勾选，这一列暂时不显示、不打印，宽度自动分给别的列（数据保留）
       宽度       —— 数字越大越宽，软件按纸张宽度自动等比缩放，不用填毫米
       删除       —— 把这一列彻底从单据里去掉（保存时该列数据不再写入）
     窗口底部「＋ 添加列」可随时加新列，加完改个列名（比如“备注”“单价”“金额”）就能用。
     列的顺序就是打印出来的从左到右顺序，拖好后点「应用」生效；点「恢复默认」回到模板的 9 列原样。
     例：把「品号」改成「客户品号」、删掉用不上的「合同编号」、加一列「备注」、把规格型号拖到第 3 位。
  3. 现场拖宽（不改设置也能调）：把鼠标移到表格里某个表头文字的右边框上，
     光标会变成左右双箭头，按住往左/往右拖，只有「这一列」和「紧挨着的右边一列」之间的边界在动，
     其他列的宽度完全不动；松手即生效并自动保存，右侧打印预览同步变化。
     两列最小各 30px，拖到极限会停住（这时改用「列设置」填数字可以突破限制）。
     最后一列没有右边界抓手，要调它请用「列设置」。
  4. 序号列由软件自动填；「数量」列决定合计数字落在哪一格（删掉数量列时合计直接跟在“合计”二字后面）。
  5. 粘贴仍按固定顺序识别（存货编号→名称→规格→项目编号→单位→数量→品号→合同编号），
     被删掉的列对应数据不写入；新增的自定义列需要在软件里手动填或粘贴后再补。

六、整张明细导入（下载模板 → 填好 → 一键导入）
  一次要录十几行、几十行时用这个，不用一行行敲。
  1. 点明细区上方的「下载模板」，得到「送货单明细模板.xlsx」：
       · 第 1 行是表头，列名和你当前的表头完全一致（你改过列名，模板里也是新名字）
       · 下面 40 行已预先设成「文本」格式，所以 0030535 这种带前导零的存货编号、
         8-20 这种像日期的规格，都不会被 Excel 自作主张改掉
       · 表头已冻结，往下滚也能看见列名
  2. 在 Excel 里从第 2 行开始填，一行一样货；空行不用管，导入时自动跳过。
  3. 存盘（直接存 xlsx，不必另存为 CSV），回软件点「导入明细」选中这个文件。
  4. 弹窗显示“读到 N 行明细 / 按列名对上了几列”和头几行预览，确认后选：
       · 替换现有明细 —— 清空当前明细，换成文件里的
       · 追加到末尾   —— 保留现有明细，接在后面
       · 取消
  5. 列对位规则：先按列名对（你用「列设置」改过的名字也认），对不上再按默认列名对；
     文件里没有表头时，按从左到右的顺序依次套到当前各列。
  6. 也支持 .csv / .txt（逗号、分号、制表符分隔都行）。Excel 另存 CSV 时中文是 GBK
     也没关系，软件会自动识别、不会乱码；2003 版 .xls 读不了，请另存为 xlsx 或 CSV。
  7. 导入只读第一个工作表；导入完记得点「保存」把这张单存进记录库。
七、套打位置微调
  打印出来整体偏上/偏下时，点左边「版式字号」，在「上下微调」里填毫米数（正数往下、负数往上），
  一般 0.5mm 一档就能对准。左右偏移请在打印机首选项里调纸张边距，
  软件内容宽 201mm，左右各留约 20mm，在 LQ-630KII 的 82 列（约 208mm）打印范围内。
  1. 三联纸和 A4 各记各的：在「三联纸」版式下填的数字只对三联纸有效，
     切到「A4」后显示的是 A4 自己的数字（默认 0），互不干扰；来回切版式，数字都还在。
  2. 范围 -15mm ~ +15mm，填完立刻在预览和打印里生效，同时自动记住（随「导出备份」一起）。
  3. 改完想复原：把数字改回 0 就行。


八、字号（三块分开调：标头 / 单据信息 / 货物明细）
  左边「版式字号」里有三组字号加减按钮，各管一块，互不影响：
    标头       —— 最上面「公司名 ＋ 送货单/样品单/提前送货单」那行大字
    单据信息   —— 制单人、录单日期、单据编号、经办人、部门、发货仓库、客户、摘要 这三行
    货物明细   —— 表格的列名表头、每一条明细、合计/小计那一行、底部三个签字位
  1. 每组左右各一个 － / ＋，按 5% 一档调，范围 60% ~ 200%，当前百分比显示在中间；
     不是 100% 时数字变蓝，一眼能看出这块被改过了。
  2. 点一下立刻在右侧预览生效，同时自动记住，下次打开还是这个字号（跟着「导出备份」一起走）。
  3. 点最右边的「预设」，一键套用常用比例：标头 135% / 单据信息 130% / 货物明细 115%
     （字大一圈但不挤，事后还能再用 － / ＋ 微调）；点「复位」，三块一起回到 100%（也就是模板原样的字号）。
  4. 明细字号调大会让每一行变高，一页能装的条数随之减少，货多时自动多分页，不会压出纸外；
     规格型号放不下时照样会自动换行、必要时自动缩一点，不会挤成两行字叠在一起。
  5. 存货名称、规格型号写得长，会自动折成多行、整段印出来，不会被截成半截；
     这两格的字号和「货物明细」是同一个字号，调大字一块变、调小一块小。
     名称折成两三行时这一行就变高，一页能放的条数相应减少（6 条放不下会自动分页）。
     其他格子（编号、品号、单位、数量等）还是原来的规矩：太长时略微缩字号，保证一行放得下。
  6. 单据信息这三行的标签固定占 5 个字宽、冒号上下对齐，冒号后统一留 5pt；
     把「单据信息」字号调大时标签会变宽，右边的内容自动往右让，不会叠在一起。
  7. 这里调的是「打印出来的字号」，屏幕上左边录入区的字号不变；预览区右上角的 74%（适应）
     只是显示比例，和这里完全两回事。

九、多页与合计
  · 只打印有内容的行：一整行都没填（序号里没有数字）的空行，整行删掉不显示，
    预览和打印都不会出现；编辑区里仍保留这些空行方便继续输入。
  · 合计行紧跟最后一条明细，不再补空白行到纸底；所以只有 2 条货时，
    表格就只有 2 行，合计和下面三个签字位紧贴其下。想让单子看起来像一叠固定格式的表
    格纸（表格一路画到纸底、合计和签字位固定在下方），在「版式字号」里勾上「表格铺到纸底」。
  · 三联纸每页最多 6 行（名称/规格折行让行变高时会提前分页），货物多时自动分页，每页都带完整表头和页码。
  · 合计行下面的横线和三个签字位之间至少留 10pt；货物明细字号放大时，合计行框会自动变高，
    不会再出现「财务 / 送货人 / 购货单位签字」压在横线上的情况。
  · 中间页合计栏显示「小计」，最后一页显示「合计」；合计值始终落在「数量」列下面
    （如果把「数量」列也隐藏了，合计数字直接跟在合计两个字后面）。
  · 三联纸自带复写，打印一次即得三联，不需要打三遍。

十、数据与备份
  · 点「保存」会先弹一个命名窗：给这张单起个名字（比如「9月对账单 第一批」），
    方便以后在记录库里一眼找到；名字不填就直接用「客户 + 单据编号」，例如
    「苏州工业园区某某电子有限公司 XS-2026-11-24-00001」。名字最长 60 字，输入框里按回车即保存。
  · 点「保存」后单据进入「记录库」（左边「记录备份」→「打开记录库」），可再次打开、修改、重新打印、删除；
    记录库里每条的「名称」在客户名上方加粗显示。同日期同编号再保存会用新内容覆盖原来那条。
  · 数据存在本机 Edge 浏览器配置里；清理浏览器数据会导致记录丢失。
  · 建议每周点一次左边「记录备份」里的「导出备份」（生成 .json 文件，存到网盘或 U 盘），
    换电脑/重装后用「导入备份」恢复。
  · 列设置也会一起备份，导入后表头自定义自动恢复。

十一、常见问题
  Q：纸张左下角印出了 file:///D:/dbwork/送货单/… 这种网址？
  A：这是浏览器打印对话框自带的「页眉和页脚」，不是软件印的。两个开关一改就没：
     ① 边距选「无 / None」（选“默认”会腾出边距给页眉页脚）；
     ② 取消勾选「页眉和页脚」。
     软件每次点打印前都会弹「打印前确认这 4 项」提醒，勾了“以后不再显示”也不会丢，
     随时可在左边「版式字号」→「打印设置说明」里看。
  Q：打印出来比纸张小一圈？
  A：打印对话框里缩放被设成了“适合纸张”，改成 100%/默认。
  Q：表格竖线错位、右边被切掉？
  A：纸张选错了（还是 A4）；或纸张在拖纸器里左右没对正。
  Q：每次都要重新选纸张？
  A：在打印机首选项里把「21.47×13.98」这张表单设为默认纸张。
  Q：预览能看，但打印是空白？
  A：Edge 打印对话框里勾选了「仅打印选定区域」之类选项，取消后再打。
  Q：想改成别的公司抬头？
  A：直接改「公司名称」栏，保存一次后会记住（公司抬头属于长期设置，「新建」不会清掉它）。
  Q：屏幕上（预览）标题和表头是粗的，另存 PDF 却变细了？
  A：宋体本身没有粗体字形，浏览器以前只在屏幕上「假装」加粗，导出 PDF 就退回细体。
     现在标题和表头改成按字号描边实现真加粗，屏幕上、PDF 里、针式打印机打出来都一样粗。
     如果另存出来的 PDF 还是细的：确认窗口是重新打开的（Ctrl+F5），再看顶栏版本号是不是 v1.12 以上。
  Q：改了列设置，以后每张单都这样吗？
  A：是，列设置是全局的，一次改好长期有效；想回模板原样点「恢复默认」。

十二、A4 版式
  左边「版式字号」里的「打印版式」选「A4 纸（激光/喷墨）」即按原模板的 A4 版面输出，
  表头带浅绿色底纹，适合喷墨/激光打印或存 PDF 存档。
  列设置对两种版式同时生效；如果只调了列宽且想让 A4 也精确对模板，点「恢复默认」即可。
